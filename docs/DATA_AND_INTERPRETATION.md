# 데이터 출처와 해석 범위

GSVS17 원자료는 현재 작업의 `JAG_reproducibility_v3.zip` 안에 있던 125개 LVL을 그대로 포함했다. 재현 패키지 내부의 공식 원자료 ZIP과 파일명·바이트도 일치한다. 이번 통합에서는 새로운 실측자료를 다운로드하거나 기존 자료를 변경하지 않았다. 두 제공 코드 ZIP 자체에는 이 실측 원자료가 없었다.

- 공식 출처로 원본 패키지가 명시한 페이지: https://www.ngs.noaa.gov/GEOID/GSVS17/raw-field-data.shtml
- 파일별 해시와 재현 패키지 해시: `provenance/data_manifest.json`
- 대응 공식 원자료 ZIP SHA-256: `0b37a4706740a16e339b5448377ef9a6a2d40f987c08c8c922dec53aac47842f`
- 공개망 fixture: 원본 `data/example/offline_fixture_observations.csv`의 288개 합성 관측. 실측자료가 아니다.
- 공개 NGS 프로젝트 목록: `modules/public_validation/data/config/ngs_projects.csv`. 관측·benchmark 파일은 포함되지 않았다.

## GSVS17 결과

두 방향이 독립이고 동일한 분산을 가진다는 조건에서 왕복차 분산의 절반을 단일 관측 분산으로 해석한다. 방향 간 공분산을 이 자료만으로 분리하지 못하므로 τ_r을 실제 경로 coherence의 엄밀한 하한이나 경로별 상한의 검증값으로 사용할 수 없다. 길이의 제곱항 적합은 모형 의존적인 구간쌍 진단이며 실제 오차 기작을 식별하는 증명은 아니다.

기존 README·콘솔·그림에 남은 “coherent”, “REQUIRED”, “validates the SCALES” 등은 원본 분석의 표현을 보존한 것이다. 통합 작업에서는 그림 제목·라벨도 변경하지 않았다. 현재 원고에 적용할 때는 해당 표현을 원고의 제한된 해석 범위와 구별한다.

모형의 평균 구조, 시준기하 대안, 공간 블록 재표집과 인접 구간 집계 등 최신 논문의 추가 분석은 이 두 ZIP의 기본 분석에 모두 포함되어 있지 않다. 따라서 이번 통합본을 최신 논문 전체의 결과·Figure 재현 패키지라고 표시하지 않는다.

## 공개망 결과

기준 경로는 관측 오차가 있는 별도 경로이다. RMSE·MAE는 기준 경로와의 불일치이고 Consistency95는 기준 경로와의 일치율이다. 물리 간선을 공유하지 않는 설계가 모든 환경·기기·시기의 통계적 독립을 보장하지 않는다. 보정계수 bootstrap이 현재 검증구간에 전파되지는 않는다.

설정에 있는 논문용 최소 사례 수 20개/시험 10개는 원본 실행 코드가 강제하지 않는다. 실제 강제 조건은 훈련 4개·시험 3개와 간선 비공유다. 실행 완료만으로 실증 규모나 95% coverage를 충족했다고 해석하지 않는다. `isPublic=true`도 입력 파일의 NOAA 출처를 인증하는 기능은 아니다.

## 코드 검토에서 남긴 사항

GSVS17 최적화의 1e-12 floor 처리, addendum의 특정 분산 요약에서 σ_s를 생략하는 기존 계산, 작은 표본의 동일일자 진단 등은 원본 결과 보존을 위해 이번에 변경하지 않았다. 공개망 경로검색은 greedy 방식이며, 비공유 경로를 발견하지 못해도 존재하지 않는다는 증명은 아니다. 자세한 근거와 영향은 `REVIEW_PUBLIC.md`, `REVIEW_GSVS17.md`에 기록했다.
