# MATLAB 패키지 통합 검토·검증 결과

두 제공 MATLAB 패키지를 `JAG_leveling_unified_v1`로 통합했다. 분석 모듈은 구분하고, 실행·설정·입출력 관리·검증을 상위 계층에서 연결했다.

## 제공 내용

- 단일 실행기 `RUN_JAG`: audit, selftest, gsvs17, public-quick, public-full, all.
- MATLAB 파일 72개와 함수 선언 118개(내부 함수 포함)의 설명을 README에 수록했다. 상세 입출력 명세도 docs에 제공한다.
- 현재 작업에서 이미 검증한 GSVS17 LVL 125개를 포함하고 원본 재현 패키지·공식 입력 아카이브와의 해시를 기록했다.
- 원본 코드 ZIP 두 개는 provenance/original_archives에 보관했다.
- GSVS17 초기 그림 5개, addendum 그림 4개를 별도 보존하고 최종 그림 6개를 복사해 모은다.

## 변경한 코드

기존 MATLAB 파일 57개 중 52개는 바이트 단위로 유지했다. 변경한 5개는 공개 모듈의 필드명 대소문자 버그 수정, 관련 단위시험, 실행 경로 인수 확장과 GSVS17의 스크립트 2개 함수화다. 새 통합 계층은 15개 MATLAB 파일이다. 수치 모형과 그림 생성·설정은 바꾸지 않았다.

공개 필드명 파서는 원본에서 대문자를 먼저 지워 `FROM_SSN` 등을 잘못 처리했다. 통합본은 소문자화 후 구두점을 제거하고 대소문자 변형 회귀시험 4개를 추가했다.

## 실제 실행·비교

MATLAB R2026a Update 4, macOS arm64에서 원본과 통합본을 별도로 실행했다.

| 검증 | 결과 |
|---|---|
| 공개 모듈 기존 감사·단위시험 | 통과 |
| 통합 경로·설정·기본 스타일 회귀검사 | 통과 |
| 공개 fixture end-to-end | 288관측, 12사례, 훈련 8/시험 4, 그림 6개 생성 |
| GSVS17 전체 분석 | 125파일, 562구간, 274왕복쌍, bootstrap 2,000회 및 addendum 완료 |
| MATLAB 결과 구조체 비교 | 23개 필드 그룹이 원본과 `isequaln`으로 동일 |
| Figure 소스·설정 | 원본 plot 블록·CFG 대입·폰트 헬퍼·공개 그림 파일 동일 |
| 생성 PNG 비교 | 원본·통합본 15개 모두 픽셀 단위 동일 |
| public-full의 자료 누락 처리 | 명시 오류, 합성자료 대체 없음 |
| 성공·실패 시 환경 복원 | MATLAB path·현재 폴더·난수 상태 복원 확인 |

숫자 파일의 생성 시각·저장 위치 같은 실행 메타데이터는 비교 대상에서 제외했다. 수치 필드는 데이터 벡터, 적합, 프로파일, bootstrap, 파생량, 검증 결과 등을 포함한다. 이미지 비교는 동일한 MATLAB 환경에서 수행했다.

## 범위와 남은 자료

공개망 실측 관측·benchmark 파일은 두 ZIP에 없으므로 `public-full`의 성공 실행은 검증하지 않았다. 입력 방법은 README에 설명했다. 공개 quick/selftest의 fixture를 실측 증거로 사용하면 안 된다.

이 통합본은 제공된 두 코드 패키지의 구조화 결과다. 최신 논문의 모든 확장 재분석과 이론 실험을 대체하는 전체 재현 패키지는 아니다. GSVS17 결과는 구간 왕복차 반복성의 모형 진단이며, 경로 coherence나 경로별 상한·공분산 hull의 직접 검증으로 해석하지 않는다. 기존 README·콘솔·그림의 강한 문구를 원본 보존 자료로 구분했다.

소규모 표본/모형 가정/최적화 floor/공개망 경로탐색·보정 불확실성 등 수치 구현의 기존 한계는 docs/REVIEW_PUBLIC.md와 docs/REVIEW_GSVS17.md에 기록했다. 이번 통합에서 원본 결과를 바꾸는 분석 재설계는 수행하지 않았다.
